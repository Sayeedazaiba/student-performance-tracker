# Student Performance Tracking Using Regression

## Project Overview
This project predicts student exam scores using Machine Learning Regression algorithms based on academic and personal performance factors.

## Dataset Used
- Dataset: Student Performance Factors
- Source: Kaggle
- File: StudentPerformanceFactors.csv

## Algorithms Used
- Linear Regression
- Ridge Regression
- Lasso Regression
- Random Forest Regression
- Gradient Boosting Regression

## Features
- Data Preprocessing
- Feature Encoding
- Model Training and Evaluation
- Performance Visualization
- Exam Score Prediction

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Output
The project compares multiple regression models and selects the best model based on R² score.
